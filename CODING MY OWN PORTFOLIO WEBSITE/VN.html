Untitled Visual Novel

Untitled Visual Novel


I am working on Untitled Visual Novel with Lalaina Chandanais, a seasoned video game writer. This project is different than the others in my portfolio in the way that I am doing both the coding for the game and the artwork. Untitled Visual Novel combines 2d and 3d elements to match the unsettling and unatural theme of the game. Untitled Visual Novel is a psychological horror game about religious trauma.



The artstyle of this project takes heavy inspiration from stopmotion films such as the Corpse Bride and Coraline, as they have a way of bending reality in a way that is unnerving in a way where you just can't help but come back for more. All of the 3d art assets of the game were made by hand and scanned into the game. Below are some images of the puppet fabrication process. We wanted the proportions of the puppets to be slightly altered so they were more offputting.





Though this game is early in the development stage, it has a lot of support by different groups of people. The setting for this game is inspired by older Victorian styles of living.
