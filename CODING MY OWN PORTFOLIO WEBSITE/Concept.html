Apothecary

Apothecary Arena


This game was developed as a class exercise with a small group. The goal was to make a fun and playable game without our scope getting too large. I feel confident that we succeeded in this task. All of the people who playtested this game ended up loving it and several asked when it would be released. Though it started out as a class project, there has been discussion between me and my groupmates about making this game a reality. Whether it will become something more is up in the air.





This game can be up to 4 players, each player being an apothecary with the goal of foraging different plants to brew into potions. The objective of this game is to be the last player standing, and there are many different ways you can go about doing so. Each player has three hearts; once a player is out of hearts, they are dead and out of the game.
